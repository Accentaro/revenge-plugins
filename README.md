# Plugins for revenge-next
These plugins have been created before in other various projects, i am not the creator, simply a contributor/maintainer.
These are my own variations. tweaked to my own personal liking.

I will PR to community repo when i'm happy with them and find no more bugs etc.

## How to install
Copy the repository URL below into **Settings > Plugins > Advanced > Add repository**. Open **Browse Plugins**, install the plugin, enable it, and restart Discord.

This repo is only for `revenge next`, and will not work for other clients.

> https://accentaro.github.io/revenge-plugins/

## Plugins

### ServerDrawer
A compact server dock with a searchable server and DM drawer, grid/list layouts, folders, drag and drop, unread indicators, native gestures, mark as read.
By **kmmiio99o, Rosie, and Benjii**.

### Declutter
Hide profile cosmetics, server tags, badges, server boost goals, DM activity cards and payment settings, with optional channel name emoji removal.
By **kmmiio99o, Benjii**.

### GIF Collections
Organise GIFs into collections, import and export JSON backups, and optionally sync using your own server endpoint.
By **Benjii**

### GIF Providers
Search Tenor, Giphy and Klipy together in the GIF picker.
By **Livie, Benjii**.

### Quoter
Create quote images from messages, preview them and send them as attachments.
By **Benjii**

### Better You Bar
Introduces a favorites and settings button to the you bar.
by **Joamonca, Benjii**

### GIF to Chat Input
Places GIF picker selections in the chat input instead of sending them immediately.
By **j, Benjii**.

### Better Badges
Allows you to rearrange all badges, including globalbadges, and hide any badge.
